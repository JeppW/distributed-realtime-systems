# Distributed Real-Time Systems (02225) — Group 37

**DTU Spring 2026**

This repository contains Group 37's code for Projects 1 and 2 in the course
02225 Distributed Real-Time Systems at the Technical University of Denmark (DTU).

## Repository Structure

| Folder | Description |
|--------|-------------|
| `DRTS-Mini-Project-1/` | Project 1 — Schedulability Analysis & Simulation (DM & EDF) |
| `DRTS-Mini-Project-2/` | Project 2 — TSN Analysis & Simulation (SP & CBS) |

Each subfolder contains its own `README.md` with setup instructions and usage details.
